        Methods & sources

        Every number on this page is reproduced from the public Taskmarket API (https://api.taskmarket.dev), no key needed. A scheduled job fetches the data server-side once an hour and commits it to this repository; this page only reads those committed files — it never calls the API from your browser.

          Reward volumes are the API's base-unit values divided by 1,000,000 and shown in dollars (OUSD on Tempo, USDC on Base). Breakdowns, time series and heatmaps are returned platform-wide by the API — the same totals for both chain IDs — while market stats differ only in paid workers and active wallets. Per-chain splits are computed from the /api/tasks list, which is chain-specific. Distinct posters per week are counted from that same list (… tasks at the last fetch). Addresses are shown shortened and never given a name. Nothing here is estimated or invented.
